**TCC EtecGames** is a web platform developed as my **Technical Course Final Project (TCC)** at **ETEC**, designed to work as a **repository and launcher for applications and games created by students** during their technical education program.

The platform aims to provide a **centralized hub** where student projects can be **published, discovered, and showcased**, preserving and highlighting the work developed throughout **technical school courses**.

> This project is the **original version** of the concept, later redesigned and improved in [EtecGames Remake](https://github.com/4NUB1Ss2/etecGamesRemake-backend) with a stronger focus on architecture and scalability.

---

## 📌 About

**TCC EtecGames** was built to solve a real problem: student projects created during technical courses often go unnoticed after completion. This platform centralizes them in one place, making them accessible to students, professors, and the community.

**Core goals of the platform:**

- Showcase **games and applications** built by ETEC students
- Provide a **browsable catalog** of student projects
- Serve as a **launcher** to access and run published projects
- Support **session management** for authenticated users

## 🚀 Features

- **Student project catalog** — browse games and apps built at ETEC
- **Platform launcher** — direct access to published projects
- **Session management** — user authentication and session control
- **MySQL integration** — relational database for project data storage
- **Responsive frontend** — built with SCSS and vanilla JavaScript

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/4NUB1Ss2/TCC_etec_games.git
cd TCC_etec_games
```

Install Node.js dependencies:

```bash
npm install
```

Configure your database connection in the appropriate config file, then start a local PHP server:

```bash
php -S localhost:8000 -t site/
```
